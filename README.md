# devsiam-com/.github

Org-wide defaults for **Devsiam** repositories.

| Path | Purpose |
|---|---|
| `profile/README.md` | Public org profile at github.com/devsiam-com |
| `.github/pull_request_template.md` | Default PR template for every repo |
| `.github/ISSUE_TEMPLATE/` | Default issue forms (bug, feature) |
| `CONTRIBUTING.md`, `SECURITY.md` | Default contribution and security policy |
| `docs/github-standard.md` | Devsiam GitHub standard (branching, commits, PRs, releases) |
| `workflow-templates/` | Starter CI shown under *Actions → New workflow* |
| `.github/workflows/reusable-*.yml` | Reusable CI called from other repos |

> **This repo is PUBLIC.** Never commit secrets, internal hostnames or IPs, GCP project IDs, client names, or client data. CI scans every PR with gitleaks.
